## Key Highlights

- **Dynamic Internal CMS:** Custom administrative dashboard (`/dev`) for real-time project management, media uploads, contact submissions, and SEO configurations.
- **Smooth Motion & UX:** Fluid animations and momentum scrolling crafted with GSAP ScrollTrigger, Lenis, and Motion.
- **Full-Stack Architecture:** Next.js Server Actions with Supabase PostgreSQL, edge route protection, and instant cache revalidation.
- **Performance & SEO Focused:** Dynamic metadata, OpenGraph image generation, automated sitemap, and optimized asset delivery via Sharp and Next.js Image.

---

## Core Technologies

- **Frontend:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, GSAP, Lenis
- **Backend & Database:** Supabase (PostgreSQL, SSR Auth, Storage)
